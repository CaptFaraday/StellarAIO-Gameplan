# StellarAIO Pricing

*Last updated: November 2025*

## Subscription Plans

| Plan | Price | Billing | Savings |
|------|-------|---------|---------|
| **Monthly** | $99/month | Monthly | - |
| **Quarterly** | $199 | Every 3 months (~$66/month) | ~33% vs monthly |
| **Yearly** | $599 | Annually (~$50/month) | 50% vs monthly |
| **Lifetime** | $1,499 | One-time payment | Best long-term value |

## What's Included (All Plans)

All subscription tiers include the same features:

- **Full access** to the Stellar AIO bot
- **50+ supported retailer websites**
- **Real-time monitor feeds** for tracking restocks
- **Performance analytics dashboard**
- **24/7 customer support** via exclusive Discord server
- **Guides and documentation**
- **Active Discord community access**
- **Command search and shortcuts functionality**
- **Multi-language support** (25+ languages)
- **High-contrast mode options**
