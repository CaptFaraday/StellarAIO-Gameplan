## Understanding Proxies

### What is a Proxy?

A **proxy server** acts as an intermediary between your computer and the internet. When you use a proxy, your web requests go through the proxy server first, which then forwards them to the destination website. The website sees the proxy's IP address instead of your actual IP address.

Think of it like sending a letter through a friend: the recipient sees your friend's return address, not yours.

### Why Are Proxies Essential for Botting?

Proxies are critical for successful automated purchasing for several reasons:

#### 1. Avoiding IP Bans

When websites detect multiple requests coming from the same IP address, they often block that IP to prevent automated purchasing. Without proxies, all your bot tasks would come from your single home IP address, making detection trivial.

**Example**: If you run 100 tasks from your home IP, the retailer sees 100 checkout attempts from one address. This is immediately flagged as suspicious behavior.

With proxies, each task can use a different IP address, making your requests appear to come from 100 different customers.

#### 2. Bypassing Rate Limits

Retailers implement rate limiting to slow down automated requests. These limits are typically based on IP addresses. Proxies allow you to distribute your requests across many IPs, effectively bypassing these restrictions.

#### 3. Geographic Targeting

Some products are only available in certain regions, or prices vary by location. Proxies allow you to appear as if you're browsing from a specific country, state, or city.

#### 4. Increased Success Rates

By distributing tasks across multiple IP addresses, you:
- Reduce the chance of any single IP being banned
- Can run more concurrent tasks
- Decrease the likelihood of captchas
- Improve overall checkout success rates

### How Proxies Work (Technical Overview)

```
Without Proxy:
Your Computer → Website Server
(Your IP is visible)

With Proxy:
Your Computer → Proxy Server → Website Server
(Only Proxy IP is visible)
```

When you configure a proxy in StellarAIO:

1. Your task sends a request to the proxy server
2. The proxy server forwards your request to the retailer
3. The retailer responds to the proxy server
4. The proxy server sends the response back to you

This entire process adds only milliseconds of delay with high-quality proxies.

### Proxy Authentication

Most proxy providers require authentication to prevent unauthorized use. There are two common methods:

1. **Username/Password Authentication**: You provide credentials with each request
2. **IP Whitelisting**: You register your home IP with the proxy provider, and only requests from that IP are accepted

## Types of Proxies

Understanding proxy types is crucial for selecting the right proxies for your needs. Each type has distinct characteristics, use cases, and price points.

### Residential Proxies

**What They Are**: Residential proxies use IP addresses assigned by Internet Service Providers (ISPs) to homeowners. These are real residential connections, making them appear as legitimate home users.

**Characteristics**:
- Highest trust scores with retailers
- Large IP pools (often millions of IPs)
- Rotating IPs (different IP for each request or session)
- Sold by bandwidth (GB) rather than IP count
- More expensive per request but harder to detect

**Best For**:
- Sites with aggressive anti-bot measures
- Sneaker releases on Shopify, Nike SNKRS, Adidas Confirmed
- When maximum anonymity is required

**Drawbacks**:
- Higher cost per GB of data
- Speeds can vary based on the actual residential connection
- Limited control over specific IPs

### Datacenter Proxies

**What They Are**: Datacenter proxies originate from servers in data centers, not residential locations. They're created in bulk and don't have ISP affiliations.

**Characteristics**:
- Very fast connection speeds
- Inexpensive compared to residential
- Not associated with residential ISPs
- Easier for websites to detect and block
- Often sold in bulk quantities

**Best For**:
- Sites with minimal anti-bot protection
- Speed-focused applications
- Budget-conscious users
- Testing and development

**Drawbacks**:
- Easily identified as non-residential
- Higher ban rates on protected sites
- Often blacklisted by sophisticated retailers

### ISP Proxies (Static Residential)

**What They Are**: ISP proxies combine the best of both worlds. They are hosted in data centers but use IP addresses from major ISPs, making them appear residential while maintaining datacenter speeds.

**Characteristics**:
- High trust scores (appear residential)
- Consistent, fast speeds (datacenter infrastructure)
- Static IPs (same IP for extended periods)
- Unlimited bandwidth (typically)
- More expensive than datacenter, cheaper than residential per request

**Best For**:
- Account creation and farming
- Long-running sessions
- Sites requiring consistent identity
- Premium sneaker sites

**Common ISP Providers**:
- Sprint
- AT&T
- Comcast
- CenturyLink
- Windstream

### Mobile Proxies

**What They Are**: Mobile proxies use IP addresses from mobile carriers (4G/5G connections). These IPs are shared among thousands of mobile users, making them extremely difficult to ban.

**Characteristics**:
- Highest trust level (blocking would affect real mobile users)
- Rotating IPs as the mobile connection changes
- Very expensive
- Slower than other proxy types
- Limited availability

**Best For**:
- Sites with the most aggressive anti-bot measures
- Social media automation
- When all other proxy types fail

### Sneaker/Retail Proxies

**What They Are**: These are specialized proxies optimized specifically for sneaker and retail botting. They're typically ISP proxies from networks known to perform well on sneaker sites.

**Characteristics**:
- Optimized for specific retailers
- Often use premium ISP ranges
- High speeds (10 GBPS+)
- Unlimited bandwidth
- Pre-tested on sneaker sites

**Best For**:
- Shopify sneaker releases
- Footsite drops
- Pokemon Center
- Any sneaker-focused release

### Ticket Proxies

**What They Are**: Specialized proxies designed for ticket purchasing platforms like Ticketmaster, AXS, and other event ticketing sites.

**Characteristics**:
- Often use AT&T residential IPs
- Optimized for ticket site anti-bot measures
- High speed connections
- Tested for ticket site compatibility

**Best For**:
- Concert ticket purchases
- Sporting event tickets
- Theater and show tickets
- Any high-demand event ticketing

## Frequently Asked Questions

### General Questions

**Q: Is using a bot legal?**
A: Using automation software to make purchases is legal in most jurisdictions. However, some retailers prohibit bot use in their terms of service, which could result in order cancellations or account bans.

**Q: Will my orders get cancelled?**
A: There's always a risk of cancellation when using bots. Success depends on proper proxy usage, profile configuration, and following best practices shared in the community.

**Q: Can I run StellarAIO on multiple computers?**
A: Each license is valid for one device. You can purchase an "Extra Instance" add-on to run on additional devices.

### Proxy Questions

**Q: How many proxies do I need?**
A: A general rule is 1 proxy per task. For important releases, having 2-3x your task count in proxies provides flexibility if some get banned.

**Q: Can I use free proxies?**
A: Free proxies are strongly discouraged. They're typically slow, unreliable, and often already banned on retail sites. They also pose security risks as your traffic passes through unknown servers.

**Q: What's the difference between rotating and static proxies?**
A: Rotating proxies change IP addresses periodically or per request. Static proxies maintain the same IP throughout your session. Rotating is better for avoiding detection; static is better for session-based activities.

**Q: Why do my proxies keep getting banned?**
A: Common causes include:
- Running too many tasks per proxy
- Using datacenter proxies on protected sites
- Proxies were previously abused
- Not rotating proxies between releases

### Technical Questions

**Q: What internet speed do I need?**
A: A stable connection is more important than raw speed. 50+ Mbps is recommended, but consistent low latency matters more than bandwidth.

**Q: Should I use a VPN with StellarAIO?**
A: Generally, no. VPNs add latency and are unnecessary when using proxies. Your bot traffic already goes through proxies; adding a VPN layer only slows things down.

**Q: What's task delay?**
A: Task delay is the time between retry attempts when a task fails. Lower delays are more aggressive but increase ban risk. Higher delays are safer but may miss fast sellouts.
